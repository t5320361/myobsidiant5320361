## 1. 課程總定位

這門課不是傳統會計課，也不是會計考試課。

這門課的定位是：

> 使用 AI 輔助學習投資取向的會計基礎，建立閱讀財報、檢查財報品質、判斷公司財務體質的能力。

本課不以培養會計人員為目標，而是幫助學習者成為能理解財報數字、判斷企業獲利品質與現金品質的長期投資學習者。

本課重點不是「會做帳」，而是：

> 看懂帳、讀懂帳、檢查帳，並把財報數字連回投資判斷。

---

## 2. 課程北極星

本課的長期北極星是：

> 成為能獨立判斷一家公司值不值得長期投資的價值投資者。

但本課不是完整投資課。

完整投資判斷至少包含四根支柱：

1. 產業分析
2. 公司分析
3. 財報分析
4. 盡職調查

本課主要處理第 3 根支柱：

> 財報分析與會計基礎。

其他三根支柱只會在需要時作為背景說明，不在本課深入展開。

---

## 3. 本課核心三問

本課所有會計概念，最後都要回到三個問題：

1. 獲利真不真？
2. 現金真不真？
3. 數字有沒有破綻？

這三個問題是本課的核心檢查框架。

| 核心問題 | 對應能力 | 主要報表 |
|---|---|---|
| 獲利真不真？ | 判斷公司帳面獲利是否可靠 | 損益表 |
| 現金真不真？ | 判斷公司是否真的收到現金、能否自我造血 | 現金流量表 |
| 數字有沒有破綻？ | 判斷三表是否互相說得通，科目是否有異常 | 資產負債表、現金流量表、附註 |

---

## 4. 課程設計原則

本課採用以下設計原則：

1. 先理解，再記憶。
2. 先讀帳，再談估值。
3. 先懂三大報表，再做財務比率。
4. 先看現金，再相信淨利。
5. 先建立固定流程，再增加工具。
6. 每個概念都要連回投資判斷。
7. 每一課都要產出筆記、Flashcards、檢查清單與練習題。
8. 分錄只用來解釋邏輯，不要求熟練做帳。
9. 管理會計不作為主線，只在第 1 課用來區分財報使用者視角。
10. 三表勾稽是全課核心主軸，不是附屬觀念。

# A. 地基：建立投資人看財報的視角

---

## 第 1 課：財報是什麼、給誰看

### 核心問題

財報到底是什麼？  
它是寫給誰看的？  
投資人看財報，和公司編製者看財報，有什麼不同？

### 一句話結論

> 財報是企業對外溝通財務狀況與經營成果的標準化語言，投資人要透過它判斷公司是否值得進一步研究。

### 學習目標

學完本課後，應該能夠：

1. 說明會計不是單純記帳，而是商業溝通系統。
2. 說明財報為什麼是標準化資訊。
3. 區分投資人視角與編製者視角。
4. 認識四大報表的基本功能。
5. 理解外部財報有用，但不是公司全部真相。

### 核心概念

- 會計是商業溝通系統
- 財報是對外溝通工具
- 投資人、債權人、監管機構的資訊需求不同
- 投資人關注報酬與風險
- 債權人關注還款能力與現金流
- 編製者關注如何依照準則表達公司活動
- 四大報表全景圖
- 外部財報的限制

### 投資判斷連結

投資人不是直接進入公司內部看真相，而是透過財報看到被會計規則整理過的版本。

所以投資人要知道：

> 財報不是自然存在的事實，而是經過辨認、衡量、分類、彙總與揭露後的資訊。

### 建議公司案例

| 案例 | 用途 |
|---|---|
| 台積電 | 認識大型上市公司的財報全景 |
| 鴻海 | 認識製造與代工企業的財報結構 |
| 中華電信 | 認識穩定現金流公司的財報特徵 |

### 本課產出

- 永久筆記：財報是企業對外溝通的標準化語言
- 比較表：投資人視角 vs 編製者視角
- Flashcards：5 張
- 練習題：判斷不同使用者會關注哪些財報資訊
- 檢查清單：第一次看財報時應該先問的問題

### 本課驗收標準

1. 能用自己的話說明「會計是商業溝通系統」。
2. 能說出四大報表各自大致回答什麼問題。
3. 能區分投資人與編製者的視角。
4. 能說明外部財報的用途與限制。

## 第 2 課：應計基礎的邏輯

### 核心問題

為什麼營收不等於現金？  
為什麼公司明明沒有付出現金，卻會有折舊費用？  
為什麼淨利不等於現金增加？

### 一句話結論

> 應計基礎讓財報反映經營成果，而不是只記錄現金進出；這也是淨利與現金流會不同的根本原因。

### 學習目標

學完本課後，應該能夠：

1. 區分現金基礎與應計基礎。
2. 說明為什麼營收不等於收現。
3. 說明為什麼費用不等於付現。
4. 理解折舊是非現金費用。
5. 理解分錄只是一種表達交易邏輯的工具，不是本課主線。

### 核心概念

- 現金基礎
- 應計基礎
- 收入認列
- 費用配合
- 應收帳款
- 應付費用
- 折舊
- 非現金費用
- 淨利不等於現金

### 本課小節設計

#### 2-1 現金基礎 vs 應計基礎

現金基礎只在收到或付出現金時記錄。  
應計基礎則在權利產生或義務發生時記錄。

#### 2-2 營收不等於收現

公司賣出商品或提供服務後，即使尚未收到現金，也可能認列營收，同時產生應收帳款。

#### 2-3 折舊不是付現

公司購買設備時，現金已經流出；後續每期認列折舊，是把設備成本分攤到使用期間。

#### 2-4 借貸與分錄只作為邏輯工具

本課只用簡單分錄說明：

- 一筆交易會同時影響兩個以上項目
- 收入、費用、資產、負債、權益如何連動
- 不要求熟練做完整分錄

### 投資判斷連結

應計基礎是投資人檢查盈餘品質的起點。

投資人要問：

1. 公司認列的營收是否真的收得到現金？
2. 應收帳款是否異常增加？
3. 費用是否被延後或資本化？
4. 折舊政策是否影響淨利？
5. 淨利是否有營業現金流支持？

### 建議公司案例

| 案例 | 用途 |
|---|---|
| 台積電 | 折舊與高資本支出 |
| 零售業公司 | 現金銷售與應收差異較小 |
| 建設公司 | 收入認列與現金收款時間差 |

### 本課產出

- 永久筆記：應計基礎是淨利不等於現金的根本原因
- 比較表：現金基礎 vs 應計基礎
- Flashcards：8 張
- 練習題：判斷交易何時認列收入與費用
- 檢查清單：淨利與現金流差異初步檢查

### 本課驗收標準

1. 能說明為什麼營收不等於收現。
2. 能說明為什麼折舊是費用但不會造成當期現金流出。
3. 能說明應收帳款如何讓淨利和現金流不同步。
4. 能回答「為什麼淨利不等於現金」。

# B. 三大報表逐一拆

---

## 第 3 課：資產負債表

### 核心問題

公司在某一個時間點有什麼、欠什麼、剩什麼？  
資產增加到底代表公司變強，還是只是借更多錢？

### 一句話結論

> 資產負債表是一張特定時間點的財務快照，用來看公司的資產結構、資金來源與財務體質。

### 學習目標

學完本課後，應該能夠：

1. 說明資產、負債、股東權益的基本意義。
2. 理解會計恆等式：資產 = 負債 + 股東權益。
3. 區分資金用途與資金來源。
4. 初步判斷公司財務體質。
5. 認識資產負債表常見科目。

### 核心概念

- 資產
- 負債
- 股東權益
- 會計恆等式
- 流動資產
- 非流動資產
- 流動負債
- 非流動負債
- 保留盈餘
- 財務體質

### 投資判斷連結

資產不是越多越好。重點是：

> 資產是靠真正獲利累積而來，還是靠大量舉債堆出來？

投資人要問：

1. 現金是否足夠？
2. 應收帳款是否過高？
3. 存貨是否可能有跌價風險？
4. 固定資產是否能帶來報酬？
5. 負債是否造成償債壓力？
6. 股東權益是否穩定累積？

### 建議公司案例

| 案例 | 用途 |
|---|---|
| 台積電 | 高固定資產、高資本支出 |
| 中華電信 | 穩定資產與現金流 |
| 高負債公司 | 觀察槓桿與償債壓力 |

### 本課產出

- 永久筆記：資產負債表看的是財務體質
- 比較表：資產、負債、股東權益
- Flashcards：8 張
- 練習題：判斷交易如何影響資產負債表
- 檢查清單：資產負債表快速檢查問題

### 本課驗收標準

1. 能解釋會計恆等式。
2. 能說明資產、負債、權益的差異。
3. 能指出資產增加不一定代表公司變好。
4. 能初步讀懂資產負債表的大分類。

## 第 4 課：損益表

### 核心問題

公司一段期間到底賺了多少？  
毛利、營業利益、稅前淨利、稅後淨利各自代表什麼？

### 一句話結論

> 損益表用來拆解公司獲利來源，投資人不能只看淨利，必須看獲利是在哪一層產生的。

### 學習目標

學完本課後，應該能夠：

1. 說明損益表的基本結構。
2. 區分營收、毛利、營業利益、稅前淨利、稅後淨利。
3. 理解本業獲利與業外損益的差異。
4. 初步判斷公司獲利品質。
5. 說明為什麼高淨利不一定代表高品質獲利。

### 核心概念

- 營收
- 銷貨成本
- 毛利
- 毛利率
- 營業費用
- 營業利益
- 業外收入
- 業外費用
- 稅前淨利
- 稅後淨利
- 每股盈餘

### 投資判斷連結

損益表的重點不是只看公司有沒有賺錢，而是看：

> 公司是靠本業穩定賺錢，還是靠一次性、業外、會計認列撐起淨利？

投資人要問：

1. 毛利率是否穩定？
2. 營業利益是否成長？
3. 費用率是否失控？
4. 淨利是否受到業外損益影響？
5. 一次性利益是否讓獲利看起來比較好？
6. 營收成長是否真的帶來利益成長？

### 建議公司案例

| 案例 | 用途 |
|---|---|
| 台積電 | 高毛利與本業獲利 |
| 鴻海 | 低毛利、大規模製造 |
| 品牌型公司 | 毛利率與品牌力的關係 |

### 本課產出

- 永久筆記：損益表要分層看，不只看淨利
- 比較表：毛利、營業利益、稅前淨利、稅後淨利
- Flashcards：8 張
- 練習題：拆解一家公司損益表
- 檢查清單：損益表獲利品質初步檢查

### 本課驗收標準

1. 能說明損益表每一層獲利的意義。
2. 能分辨本業獲利與業外損益。
3. 能說明為什麼淨利不能單獨判斷公司好壞。
4. 能用毛利率與營業利益率提出初步問題。

## 第 5 課：現金流量表

### 核心問題

公司真的有收到現金嗎？  
現金從哪裡來，又花到哪裡去？

### 一句話結論

> 現金流量表是檢查盈餘含金量的報表，能幫助投資人判斷淨利是否有現金支持。

### 學習目標

學完本課後，應該能夠：

1. 區分營業、投資、籌資三種現金流。
2. 說明營業現金流和淨利的差異。
3. 理解投資現金流與資本支出的關係。
4. 理解籌資現金流與借款、股利、增資的關係。
5. 初步判斷公司是否有自我造血能力。

### 核心概念

- 營業活動現金流
- 投資活動現金流
- 籌資活動現金流
- 期初現金
- 期末現金
- 資本支出
- 股利
- 借款
- 現金增減
- 盈餘含金量

### 投資判斷連結

現金流量表不是「不能造假」的報表，但它比損益表更能幫助投資人檢查淨利品質。

投資人要問：

1. 營業現金流是否長期為正？
2. 營業現金流是否支持淨利？
3. 投資現金流是否因資本支出大量流出？
4. 公司是否靠借款補現金缺口？
5. 股利是否由自由現金流支持？
6. 期末現金是否穩定？

### 建議公司案例

| 案例 | 用途 |
|---|---|
| 台積電 | 高營業現金流與高資本支出 |
| 中華電信 | 穩定營業現金流 |
| 高成長但現金流差公司 | 檢查獲利與現金背離 |

### 本課產出

- 永久筆記：現金流量表是檢查盈餘含金量的工具
- 比較表：營業、投資、籌資現金流
- Flashcards：10 張
- 練習題：比較淨利與營業現金流
- 檢查清單：現金流量表快速檢查問題

### 本課驗收標準

1. 能說明三種現金流。
2. 能說明營業現金流和淨利的差異。
3. 能看出公司是否靠本業創造現金。
4. 能說明為什麼現金流量表能檢查盈餘品質。

# C. 主軸課：把零件變成機器

---

## 第 6 課：三表勾稽

### 核心問題

資產負債表、損益表、現金流量表不是三份獨立文件。  
它們是怎麼互相連動的？

### 一句話結論

> 三表勾稽是本課的轉折點：前面學的是零件，這一課開始把零件組成一台能運作的財報機器。

### 學習目標

學完本課後，應該能夠：

1. 說明淨利如何影響保留盈餘。
2. 說明折舊如何降低淨利，但在現金流量表中加回。
3. 說明應收帳款如何讓營收與現金脫鉤。
4. 說明資本支出如何影響現金流量表與資產負債表。
5. 說明借款與股利如何連動籌資現金流、現金與權益。
6. 用一個小案例跑完整三表連動。

### 核心概念

- 三表勾稽
- 淨利
- 保留盈餘
- 折舊加回
- 應收帳款變動
- 存貨變動
- 資本支出
- 借款
- 股利
- 期末現金

### 本課核心小案例

建議用一個簡化案例貫穿三表：

```text
某公司期初現金 100
本期借款 50
購買設備 80
本期營收 120，其中 90 收現，30 尚未收現
本期現金費用 60
本期折舊 10

```

透過這個案例觀察：

| 報表 | 連動重點 |
|---|---|
| 損益表 | 營收 120 - 現金費用 60 - 折舊 10 = 淨利 50 |
| 現金流量表 | 收現、付現、買設備、借款、發股利如何影響現金 |

| 權益變動 | 淨利增加保留盈餘，股利減少保留盈餘 |

### 投資判斷連結

三表勾稽直接對應本課核心三問：

| 核心問題 | 勾稽檢查 |
|---|---|
| 獲利真不真？ | 損益表淨利是否有營業現金流支持 |
| 現金真不真？ | 現金流量表是否能解釋資產負債表現金變動 |

### 本課產出

- 永久筆記：三表勾稽把財報零件變成一台機器
- 三表連動圖
- Flashcards：10 張
- 練習題：用簡化交易完成三表連動
- 檢查清單：三表勾稽快速檢查問題

## 第 11 課：比率分析

### 核心問題

如何用少數關鍵比率快速判斷公司財務狀況？

### 學習目標

學完本課後，應該能夠：

1. 認識獲利性、安全性、效率、現金創造力四類比率。
2. 理解比率不能單獨看，要看趨勢與同業比較。
3. 初步計算常見財務比率。
4. 用比率找出需要深入查證的問題。
5. 避免把工具評分當成買賣訊號。

### 核心概念

- 毛利率
- 營業利益率
- 淨利率
- ROE
- ROA
- 負債比
- 流動比率
- 速動比率
- 應收帳款週轉率
- 存貨週轉率
- 營業現金流對淨利比
- 自由現金流

### 投資判斷連結

> 這個比率高不高？

而是：

> 這個比率和過去相比、和同業相比、和公司商業模式相比，是否合理？

投資人要問：

1. 獲利能力是否穩定？
2. ROE 是靠本業能力，還是靠高槓桿？
3. 負債是否過高？
4. 營運效率是否變差？
5. 現金流是否支持淨利？
6. 比率異常背後的原因是什麼？

### 比率分類

| 類型 | 代表比率 | 核心問題 |
|---|---|---|
| 獲利性 | 毛利率、營業利益率、淨利率、ROE | 公司賺錢能力如何？ |
| 安全性 | 負債比、流動比率、速動比率 | 公司財務風險高不高？ |
| 效率 | 應收週轉、存貨週轉 | 公司營運效率好不好？ |
| 現金創造力 | 營業現金流對淨利比、自由現金流 | 獲利有沒有現金支持？ |

### 本課產出

- 永久筆記：財務比率是提問工具，不是答案

- 檢查清單：比率分析閱讀順序

- 資產減損

> 公司有沒有賺錢？

### 紅旗清單

| 紅旗 | 可能代表的問題 |

| 負債快速增加 | 財務風險升高 |

| 主題 | 本課深度 |
|---|---|
| 本益比 | 理解概念與限制，不做完整買賣判斷 |
| 股價淨值比 | 理解和資產、ROE 的關係 |
| DCF | 只理解價值來自未來現金流折現 |
| 自由現金流 | 連回現金流量表與資本支出 |
| 安全邊際 | 理解概念 |
| 估值模型 | 不深入建模，留到下一門課 |

### 本課產出

- 比較表：本益比、股價淨值比、DCF

- 練習題：判斷不同估值方法適合問什麼問題
- 下一門課問題清單：估值專課要學什麼
