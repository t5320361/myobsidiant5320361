## 4. 偏好的學習方式

請用以下方式教我：

1. 先給結論
2. 說明問題本質
3. 用簡單定義解釋概念
4. 用表格比較差異
5. 用具體例子說明
6. 拆成可執行步驟
7. 最後給我檢查清單或下一步

適合我的教學流程：

```text
概念定義
→ 為什麼重要
→ 常見誤解
→ 一個簡單例子
→ 操作步驟
→ 練習題
→ 檢查清單
→ 下一步
```

## 7. 學習風險

### 7.1 容易把「收集」誤認成「學會」

我很會找工具、找資料、找方法，但真正的學習不在於收集多少，而在於：

- 是否能複述
- 是否能解釋
- 是否能使用
- 是否能判斷對錯
- 是否能遷移到新情境

---

### 7.2 系統容易過度複雜

我容易同時使用太多工具：

- Readwise
- Obsidian
- RemNote
- MarginNote
- Flashcards
- 卡片盒
- 增量閱讀
- AI 摘要
- OCR
- Markdown
- GitHub

需要控制系統複雜度，優先建立最小可用系統。

---

### 7.3 真正卡住的地方可能是執行一致性

很多時候，更好的方法不是換工具，而是固定流程。

例如：

```text
每天閱讀 20 分鐘
→ 畫 3 條重點
→ 寫 1 張永久筆記
→ 做 1 張 Flashcard
→ 隔天複習
```

這種流程比一直換工具有效。

---

## 8. 最適合我的學習系統架構

```text
第一層：輸入
Readwise Reader / 書 / 文章 / 影片 / PDF

第二層：擷取
劃線、摘錄、OCR、重點筆記

第三層：理解
用自己的話改寫、整理概念、問問題

第四層：記憶
Flashcards、RemNote、FSRS、間隔重複

第五層：輸出
工作表、文章、投資分析、英文句子、流程設計
```

目前最該強化的是第三層和第五層。

因為很多人會卡在：

> 有輸入，有摘錄，但沒有真正理解，也沒有輸出。
